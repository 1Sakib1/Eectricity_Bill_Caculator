# Smart Electricity Bill Calculator ⚡

[![Live Demo](https://img.shields.io/badge/Live_Demo-Click_Here-blue?style=for-the-badge&logo=github)](https://1sakib1.github.io/Eectricity_Bill_Caculator/)

A beautiful, interactive, client-side web application to calculate electricity bills based on dynamic tier usage. Completely redesigned from the ground up to feature modern glassmorphism UI and a multi-language translation engine!

### ✨ Features
* **100% Client-Side:** Runs completely in the browser (HTML, JS, Tailwind CSS). No backend required!
* **Multi-Language Support (i18n):** Instantly switch between English, Spanish, French, Bengali, and Hindi.
* **Tiered Math Logic:**
  * First 50 units @ $3.50
  * Next 100 units @ $4.00
  * Next 100 units @ $5.20
  * Above 250 units @ $6.50
* **Dynamic Breakdown:** Beautifully rendered receipt detailing exactly how much was charged per tier.
